# 癒やし系の猫壁紙をランダム表示する

## 目的

新しいタブを開くたびに異なる猫の壁紙を表示し、穏やかな印象を与える。

## 壁紙

- `public/images/` に、1920×1080 の癒やし系猫壁紙を3枚追加する。
- やわらかい朝・夕方の光と、淡い青紫・ピンクを基調にする。
- 猫は画面中央を避け、時計とポモドーロタイマーの視認性を保つ。
- 既存の壁紙も候補として残す。

## 表示方法

- 背景候補のパスをページ内の定数として管理する。
- 初期の静的HTMLでは既存の背景を表示する。
- クライアント側で読み込み後、候補から1枚をランダムに選んで背景を更新する。
- すべてのパスには既存の `getUrl(...)` を使用し、`URL_PREFIX` 配下の静的公開でも動作させる。

## 検証

- 背景候補とランダム選択のロジックをテストする。
- `npm run lint` と `npm run build` を実行し、静的エクスポートを確認する。
